# java-lotto-precourse

### 입력
- [x] 구입 금액 입력
- [x] 당첨 번호 입력
- [x] 보너스 번호 입력

### 파싱 및 검증
- [x] 구입 금액 문자열 정수로 변환
  - [x] 입력이 숫자가 아니면 예외
  - [x] 입력이 비어있다면 예외
  - [x] 1000보다 낮은 숫자이면 예외
  - [x] 1000으로 나누어 떨어지지 않으면 예외
- [x] 당첨 번호 문자열 파싱
  - [x] ','로 숫자 구분
  - [x] 나눈 요소가 비어있다면 예외
  - [x] 나눈 요소가 숫자가 아니라면 예외
  - [x] 나눈 요소가 6개가 아니라면 예외
  - [x] 나눈 요소가 1~45에 해당하지 않는다면 예외
- [x] 보너스 번호 정수로 변환
  - [x] 입력이 비어있다면 예외
  - [x] 숫자가 아니라면 예외
  - [x] 입력이 1~45에 해당하지 않는다면 예외

### 로또 발행
- [x] 구입 금액만큼 로또 발행
- [x] 로또 하나 당 1~45 범위의 숫자에서 6개 숫자 뽑기

### 당첨 내역 계산
- [x] 당첨 기준에 따라 1등, 2등, 3등, 4등, 5등 개수 계산
- [x] 수익 금액 계산
- [x] 수익률 계산 (소수점 둘째 자리에서 반올림)

### 출력
- [ ] 발행한 로또 출력
  - [ ] 발행한 로또 수량 출력
  - [ ] 발행한 로또의 번호 오름차순으로 출력
- [ ] 당청 내역 출력
  - [ ] 5등부터 1등까지 각 일치 개수 출력
  - [ ] 수익률 출력
- [ ] 예외 상황 시 "[ERROR]"로 시작하는 에러 문구 출력
